# Before publishing

- [ ] Confirm with teammates and CentraleSupélec that the selected group code may be published.
- [ ] Confirm that no dataset, model, plot or code snippet discloses restricted patient information.
- [ ] Review source scripts for embedded patient identifiers, internal URLs, credentials or other restricted information.
- [ ] Verify attribution and individual contributions with the team.
- [ ] Review dependency installation and execution with authorized data; no reproducibility claim is made yet.
- [ ] Create a **new** GitHub repository; do not copy the original GitLab `.git` history.
- [ ] Do not choose a permissive license unless the relevant rights holders agree.
